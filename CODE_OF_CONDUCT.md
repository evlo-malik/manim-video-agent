# Code of Conduct

## Our standard

We commit to a respectful, harassment-free community. Be considerate, accept constructive feedback, focus discussion on the work, and assume good intent while addressing harmful behavior directly.

Unacceptable behavior includes harassment, discrimination, threats, sexualized attention, deliberate intimidation, and publishing another person's private information without permission.

## Enforcement

Report conduct concerns privately through the repository owner's GitHub profile. Maintainers may edit or remove contributions and temporarily or permanently restrict participation when behavior threatens a safe, productive community.

This policy applies in project spaces and when someone publicly represents the project.
